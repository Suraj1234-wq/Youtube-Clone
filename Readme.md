# ▶️ YouTube Clone (Frontend)

A responsive **YouTube Clone UI** built using **HTML, CSS, and JavaScript**.  
This project replicates the layout and basic functionality of YouTube including navbar, sidebar, and video grid.

---

## 🚀 Features

- 📺 YouTube-style homepage UI  
- 📱 Fully Responsive Design (Mobile + Tablet + Desktop)  
- 📂 Sidebar with toggle (JavaScript)  
- 🔍 Search bar UI  
- 🎬 Video cards with thumbnails  
- 🎨 Hover effects and smooth animations  
- 🌙 Dark theme UI  

---

## 🛠 Tech Stack

- HTML5  
- CSS3 (Flexbox + Grid)  
- JavaScript (DOM Manipulation, Events)
